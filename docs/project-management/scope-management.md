# Scope Management

## In scope
1. Customer dashboard and demo journeys.
2. REST API demonstration.
3. GCP target architecture.
4. Terraform blueprint.
5. Security, observability and DR design.
6. DevSecOps pipeline and quality gates.
7. Project governance artifacts.

## Out of scope
Live payments, real customer onboarding, production credentials, regulatory approval, live banking integrations and irreversible cloud deployment.

## Scope control
Every proposed change is assessed for business value, architecture impact, security impact, schedule/cost impact and acceptance criteria before approval.
