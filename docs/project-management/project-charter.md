# SecureBank Project Charter

**Purpose:** Design and demonstrate a secure, resilient digital banking platform architecture on Google Cloud.

**Business objective:** Provide a scalable reference platform for account access, transactions, notifications, analytics and operational resilience while reducing coupling and improving delivery governance.

**Success measures:** tested demo workflows; documented SLOs; parameterized infrastructure; security controls; DR plan; traceable PM artifacts.

**Sponsor:** Business/Product Sponsor (portfolio role). **Delivery lead:** Technical Project Manager / Cloud Architect. **Core team:** product, engineering, security, data, SRE and QA.

**Constraints:** synthetic data only; no production banking claims; cloud spend requires explicit approval; compliance requirements must be defined before production.
