# SecureBank Project Charter

## Purpose
Design and demonstrate a secure, resilient digital banking platform on Google Cloud while providing evidence of professional project governance.

## Objectives
- Deliver a secure customer banking experience.
- Establish a scalable cloud reference architecture.
- Demonstrate measurable reliability, security and recovery controls.
- Provide traceable scope, risks, decisions and acceptance criteria.

## Scope
Application experience, APIs, cloud architecture, infrastructure blueprint, security, observability, DR planning, testing and delivery governance.

## Out of scope
Real-money settlement, production customer data, regulated production certification and live financial integrations.

## Success criteria
Working local demo, passing automated tests, coherent architecture/IaC documentation, documented security/DR model and auditable project controls.
