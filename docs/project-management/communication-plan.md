# Communication Plan

| Audience | Information | Cadence | Channel | Owner |
|---|---|---|---|---|
| Sponsor/steering | Status, risks, decisions, budget | Monthly | Steering pack | PM |
| Product | Scope, backlog, acceptance | Weekly | Product review | PM/Product |
| Engineering | Delivery blockers, changes | Daily/weekly | Stand-up + tracker | Engineering lead |
| Security | Threats, findings, exceptions | At each gate | Security review | Security lead |
| Operations | SLOs, incidents, readiness | Weekly near release | Ops review | SRE |
| Customers/testers | Release notes, acceptance journeys | Per validation cycle | Test sessions | Product |
