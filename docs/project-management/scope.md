# Scope

## In scope
Architecture, API design, synthetic-data demo, GCP reference architecture, Terraform blueprint, security model, SLOs, DR design, CI/security automation, PM governance and operational runbooks.

## Out of scope
Real banking integration, live payment rails, real customer identity, card processing, regulatory certification, production cloud deployment and production financial data.

## Definition of scope control
Any request affecting authentication, transaction semantics, data residency, regulatory controls, production deployment or budget requires formal change assessment before implementation.
