# Delivery Roadmap

| Phase | Weeks | Outcome |
|---|---:|---|
| Discover | 1–2 | Charter, requirements, stakeholders, risks |
| Architect | 3–4 | Cloud, data, security and DR design |
| Build | 5–8 | Demo application and infrastructure blueprint |
| Assure | 9–10 | Tests, security, SLO and recovery validation |
| Release readiness | 11 | Runbooks, acceptance and change approval |
| Close | 12 | Outcomes, lessons and portfolio evidence |

**Stage gates:** architecture approval → security review → test exit → operational readiness → release approval.
