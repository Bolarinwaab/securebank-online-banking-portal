# Delivery Roadmap

| Phase | Outcome | Gate |
|---|---|---|
| 1. Discover | Personas, scope, SLOs, risks | Charter approved |
| 2. Design | Architecture, data, security, DR | Architecture review |
| 3. Build | API, UI, IaC, CI | Quality gate |
| 4. Validate | Functional/security/performance tests | Test sign-off |
| 5. Resilience | Backup restore and failover exercise | DR sign-off |
| 6. Readiness | Runbooks, support, cost and acceptance | Go-live decision |

Delivery should be milestone-driven with change control rather than calendar dates that imply an active production program.
