# Communications Plan

| Audience | Cadence | Channel | Content |
|---|---|---|---|
| Sponsor | Monthly | Steering review | Scope, budget, risks, decisions |
| Product | Weekly | Delivery review | Backlog, acceptance, blockers |
| Engineering | Daily | Stand-up | Progress, dependencies, defects |
| Security | Per gate | Security review | Findings, exceptions, residual risk |
| Operations | Weekly during release | Readiness review | SLO, monitoring, rollback, DR |
| Customers/testers | Per test cycle | Feedback channel | Usability and defects |

Escalate Sev-1 incidents immediately through the incident command process; do not wait for the normal cadence.
