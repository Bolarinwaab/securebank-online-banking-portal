# Acceptance Criteria

- [ ] Customer can view synthetic account balances.
- [ ] Customer can view synthetic transaction history.
- [ ] Invalid transfer amounts are rejected.
- [ ] Insufficient demo balance is rejected.
- [ ] Valid transfer request returns a simulated acceptance and explicitly states that no funds moved.
- [ ] Health endpoint returns service status.
- [ ] Automated tests pass.
- [ ] Security checks pass without committed secrets.
- [ ] Architecture diagrams agree with the written design.
- [ ] Terraform is parameterized and reviewable.
- [ ] Runbook, incident response, backup/restore and DR documents are present.
- [ ] README distinguishes implemented demo from production blueprint.
