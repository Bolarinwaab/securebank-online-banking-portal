# Incident Response

## Roles

- Incident commander: coordinates response and decisions.
- Technical lead: diagnoses and restores service.
- Security lead: assesses security/privacy implications.
- Communications lead: coordinates stakeholder updates.

## Severity

- **SEV-1:** critical customer impact, security incident or sustained major outage.
- **SEV-2:** material degradation with workaround.
- **SEV-3:** limited impact or non-critical defect.

## Lifecycle

Detect → Triage → Contain → Recover → Validate → Communicate → Learn.

Every incident should preserve timestamps, commands, relevant logs, deployment identifiers and decisions without copying sensitive customer data into tickets.
