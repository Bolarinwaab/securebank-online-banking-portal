# Data Provenance

## Source
The project uses the publicly available Superstore / Global Superstore benchmark family as the base analytical source. Public documentation lists transaction, customer, geography, product, sales, quantity, discount and profit attributes, with extended versions also containing market, shipping cost and order priority.

Reference sources:
- Kaggle Global Superstore dataset: https://www.kaggle.com/datasets/ronysoliman/global-superstore-dataset
- Public GitHub copy of Global Superstore 2016: https://github.com/andrewmanueld/dataset_global_superstore_2016

## Treatment
The original public data is retained as source/benchmark data. Enterprise analytical fields are derived in the SQL layer or generated by the reproducible enrichment script. Derived fields include:
- Year, Quarter, Month, Month_Name
- Discount_Band
- Net_Sales
- COGS where a consistent source profit definition permits it
- Profit_Margin
- Revenue_YoY
- Profit_YoY
- Units_YoY
- Revenue_MoM
- Revenue_Rank, Country_Rank and Product_Rank
- Performance_Status

## Governance statement
No values in this portfolio project should be interpreted as confidential company data or actual production transactions. The purpose is to demonstrate an enterprise analytics workflow and management dashboard design.
